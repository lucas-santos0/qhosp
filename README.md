# 🏥 QHosp — Gestão e Suporte Hospitalar

Projeto de TCC desenvolvido ao longo de 10 meses para auxiliar na organização e comunicação dentro de hospitais públicos.

O QHosp é composto por três aplicações integradas:

🌐 **Web** — React + Vite

📱 **Mobile** — React Native + Expo

🖥️ **Backend** — Node.js + Express
